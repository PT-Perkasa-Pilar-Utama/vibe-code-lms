# Cover Slide Asset Workflow

Use a two-step workflow for the cover animation:

1. Generate and approve the still image using `COVER_SLIDE_IMAGE_PROMPT.md`.
2. Use that approved image as the source/reference and animate it using `COVER_SLIDE_VIDEO_FROM_IMAGE_PROMPT.md`.

This workflow is intentional: composition, color, and the pure-white background are locked in the still image first, then motion is added without redesigning the asset.

Target presentation asset:
`COVER_SLIDE_RIGHT_VISUAL.mp4`

The result must feel like part of the slide itself, not like a separate embedded video.
