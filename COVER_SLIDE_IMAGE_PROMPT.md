# Google Flow / Image Model Prompt - Cover Slide Still Image

Create a clean, premium still image for the right side of a corporate presentation cover slide about building a simple LMS with AI.

This is NOT a standalone poster and NOT a dashboard screenshot.
This is a visual asset that must blend into a clean presentation slide.

## Critical background rule
BACKGROUND MUST BE PURE WHITE ONLY: #FFFFFF.
BACKGROUND IS NOT ALLOWED TO CONTAIN ANY OTHER COLOR.
NO gray.
NO blue-gray.
NO off-white tint.
NO gradient.
NO vignette.
NO haze.
NO fog.
NO atmospheric lighting.
NO colored shadows on the canvas.
NO darker corners.
NO tinted backdrop.

The entire canvas background must remain flat pure white (#FFFFFF) from edge to edge so that, when placed on a white presentation slide, the image boundary effectively disappears and the asset feels transparent.

## Main visual goal
Create a stylized LMS product illustration made from floating modular UI elements, not a full literal app screen.

Include:
- one primary learning/content card
- two or three supporting lesson/progress cards
- subtle progress elements
- small completion/check indicators
- elegant modular UI fragments related to learning flow

## Do not include
- full dashboard screenshot
- browser window frame
- laptop mockup
- device mockup
- dark scene
- colored backdrop
- noisy background
- large paragraph text
- realistic software demo screen
- hard outer panel edges that make the asset look boxed-in

## Style
- very clean
- premium
- modern
- light corporate presentation style
- editorial / keynote-like
- subtle depth only on the floating objects
- teal accents similar to #0D9488
- soft neutral UI details
- minimal dark accents only where needed

## Composition
- center the important content
- keep visual elements in the middle safe area
- leave generous pure-white breathing room around the illustration
- allow gentle crop tolerance on the outer edges
- make the visual feel balanced inside the existing slide layout

## Shadows and depth
Use soft shadows only directly underneath the floating UI elements.
The shadows must remain neutral and subtle.
Do NOT place any global shadow, ambient haze, vignette, or darker wash across the canvas.
The surrounding canvas must remain pure white (#FFFFFF).

## Final look
The final still image should feel like:
- an illustration already belonging to the slide
- a premium animated-asset base frame
- a clean LMS concept visual
- almost transparent when placed on a white slide because the canvas is exactly white

It should NOT feel like:
- a separate image pasted into the slide
- a self-contained software screen
- a cinematic product ad scene
- a rectangle with a different background

## Short version
Create a premium modular LMS product illustration for a corporate presentation cover: floating lesson, progress, and content cards with restrained teal accents. BACKGROUND MUST BE PURE WHITE #FFFFFF ONLY AND MUST NOT CONTAIN ANY OTHER COLOR, gradient, tint, vignette, fog, haze, or atmospheric backdrop. No full dashboard, no browser frame, no device mockup, no large readable text. Leave generous white space so the asset boundary disappears on a white slide.
